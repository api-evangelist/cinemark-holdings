# Cinemark Holdings

> the world, operating theatres across the United States and Latin America under the
> Cinemark, Century, Tinseltown, Rave and CineArts brands. Cinemark does not publish a

## What is machine-readable here

Nothing published by Cinemark. As of 2026-09-05 there is no OpenAPI, Swagger, GraphQL
SDL, AsyncAPI, Protobuf, WSDL, agent card, MCP server or .well-known document served from
any Cinemark-controlled host. An agent cannot call a Cinemark API today.

## Developer surface that does exist

- [Cinemark Developers (Brasil)](https://developers.cinemark.com.br/api-portal/): a
  Sensedia API Portal instance, branded for Cinemark's Brazilian operations. Free
  developer registration. The API list and interactive API Browser are gated: an
  anonymous GET of /api-portal/apis returns HTTP 403 "Acesso negado".
- [Authentication notes](https://developers.cinemark.com.br/api-portal/node/4): states
  application-level auth only — register an app under the APPs menu, send the resulting
  App-Token in a request header. NOTE: the same page's OAuth section carries Tumblr's
  OAuth endpoints, which are unmodified vendor-template placeholders and are not
  Cinemark's.
- [Error codes](https://developers.cinemark.com.br/api-portal/node/5): an HTTP status
  table (200/400/401/404/413/422/429/500), likely Sensedia boilerplate.
- [Developer registration](https://developers.cinemark.com.br/api-portal/user/register)

## What is behind a wall

The portal's Terms and Conditions, FAQ, code examples and SDK download pages are
unmodified Sensedia demo template content — Lorem ipsum, a LIPSUM-java-sdk reference, and
Evernote's SDK page copy. Treat none of it as a Cinemark contract. The real contract, if
one is published at all, sits behind the portal login.
